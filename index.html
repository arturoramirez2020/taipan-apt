🐍 TAIPAN LINUX APT Repository

This site serves .deb packages for TAIPAN Linux.

To add this APT repository to your system, run:

echo "deb [trusted=yes] https://arturoramirez2020.github.io/taipan-apt noble main" | sudo tee /etc/apt/sources.list.d/taipan.list
sudo apt update
sudo apt install taipan-settings
